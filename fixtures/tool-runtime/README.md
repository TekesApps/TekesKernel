# Tool runtime fixtures

`cases.canonical.json` is the Slice-8 bidirectional coverage registry. The
implementation must prove that its dispatcher covers exactly these 27 fixed
names and every backend/effect crash class. `artifact_contract` fixes the
per-tool and matrix filenames plus required case fields. Request/result fixtures
and supervisor-control/job transcripts are added before the corresponding
backend is advertised; they are never generated by production code.

The committed baseline contains exactly 27 `tools/<tool>.case.canonical.json`
files and the ten rows named by `matrix_cases`. `minimum-axis-cover` means each
backend, effect, and required failure occurs at least once in the smallest
possible number of real backend/effect rows; it does not claim that impossible
backend/effect combinations are executable. Every case owns exactly the five
fields listed by `required_case_fields` and is canonical JSON plus one LF.
